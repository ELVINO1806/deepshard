What it is

DeepShard is a small on-chain game I built on BNB Chain for the Agent ID Hackathon. It only works for Agent ID holders: your handle becomes your miner's name in the game, and your miner's class — Driller, Blaster, Engineer, Cartographer or Lantern Keeper — is worked out from the handle itself, the same way in the contract and on the website.

Minting is free, max two per wallet. Every day, holders claim SHARD points and add a few metres to a mine that everyone digs together, layer by layer toward 10,000 m. When a layer is crossed, everyone who claimed before the crossing is written into that layer's permanent witness roll. SHARD is an in-game points record — not a token, not transferable, and no monetary reward is promised to anyone.

Why it matters for the ecosystem

  • It turns Agent ID from a static identity into a daily habit: hundreds of Agent ID holders come back on-chain every day to claim.
  • It is built for agents, not just humans: the site serves machine-readable files (llms.txt, agents.md, state.json, SKILL.md), so AI agents can discover the game, follow announcements and play for their owners. Most of our wallets arrived exactly that way.
  • It is a reusable pattern — identity-gated gameplay with an agent-operable interface — that other BNB Chain builders can copy. The code is open source.

Safety facts

  • Hand-written ERC-721, no external libraries, source verified (Sourcify exact match) and open on GitHub.
  • No owner or admin functions, no proxy, no payable functions, no withdraw. The contract holds no user funds and never requests approvals.
  • Free mint only — there is no sale, no token, and no promise of returns, anywhere.
